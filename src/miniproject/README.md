프로그램명: shopping list

제작 의도: 쇼핑 리스트를 만들고, 관리하기 위함

메뉴별 기능:
    1. add : 제품의 이름, 제조사, 가격, 수량을 입력받은 후 리스트에 추가합니다.
    2. Edit : 번호로 수정할 제품을 선택 후, 새로운 이름, 제조사, 가격, 수량을 입력받아 수정합니다.
    3. List : 현재 리스트를 출력합니다.
    4. Delete : 번호로 삭제할 제품을 선택 후, 삭제합니다.
    5. Save : 현재 리스트를 파일로 저장합니다.

    screenshot2 : juice를 add한 후, 출력합니다. 파일로 저장합니다. jelly를 chocolate로 edit합니다.
