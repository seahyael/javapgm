# Java Programming Coursework

자바 기초 수업에서 작성한 과제와 실습 코드를 모아둔 저장소입니다. 각 과제는 주차별 폴더에 정리되어 있으며, 콘솔 프로그램과 객체지향 프로그래밍, 파일 처리, 소켓 통신 등을 연습했습니다.

A collection of assignments and exercises from an introductory Java programming course. Work is organized by week and covers console programming, object-oriented programming, file handling, and socket communication.

## 과제 둘러보기 | Coursework

| [Week 5](src/week5) | Java 기초 문법과 콘솔 실습 · Java fundamentals and console exercises |

| [Week 6](src/week6/README.md) | 배열, 합계·평균, 순서 찾기, 날짜 계산, BMI · Arrays, sums and averages, ranking, date calculations, and BMI |

| [Week 7](src/week7/README.md) | 문자열 처리, 회원가입·로그인 입력, 학부명 비교, 생년월일 처리 · String processing, sign-up and login input, name comparison, and date-of-birth processing |

| [Week 9](src/week9/README.md) | 로또 번호 생성과 문자열 관련 실습 · Lottery number generation and string exercises |

| [Week 10](src/week10/README.md) | 암호 생성, 국영수 점수 분석, BMI 계산 · Password generation, score analysis, and BMI calculation |

| [Week 11](src/week11) | 책·할 일·단어를 다루는 CRUD 및 클래스 실습 · CRUD and class exercises with books, to-dos, and words |

| [Week 12](src/week12/README.md) | 일정 관리 프로그램과 간단한 채팅 프로그램 · To-do management and a simple chat program |

| [Week 13](src/week13/README.md) | 파일을 이용한 데이터 분석과 문자 빈도 계산 · File-based data analysis and character frequency counting |

| [Week 14](src/week14/README.md) | HashMap 점수 분석, 주차장 관리, 채팅 기능 확장 · HashMap-based score analysis, parking management, and chat enhancements |

| [Mini Project: Shopping List](src/miniproject/README.md) | 쇼핑 목록 추가·수정·조회·삭제 및 파일 저장 · Add, edit, view, and delete shopping list items; save to a file |

| [Quiz](src/Quiz) | 배열과 객체를 활용한 Java 연습 · Java practice using arrays and objects |
